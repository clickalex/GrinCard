This is the live demo account. The link below is real — anyone can open it. To make it yours, only the JSON changes:
  1. Copy the repo — Fork or Use this template.
  2. Edit profile-data/yourname.json (rename the file to you) and list that username in profile-data/index.json.
  3. Settings → Pages → Deploy from a branch. Your link is https://YOU.github.io/REPO/c/YOU/ — same shape, your data.

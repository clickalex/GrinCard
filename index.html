Make this yours in three steps

No build step, no account, no server.
  1. Create your profile file. In profile-data/, add a JSON file named after the username you want in your URL — profile-data/riley.json becomes /c/riley/. Set "username" inside to match the filename exactly. On GitHub you can do this in the browser: Add file → Create new file, or edit the starter yourname.json and save it under your own name. Nothing to install.
  2. Pick a look and edit your links. The dashboard has a visual template picker and a form for your links, so you can watch the card change as you type, then use Copy to take the finished JSON back to your repo. Hand-editing works too. Public links show to anyone; "visibility": "followers_only" ones only appear on a link you send to somebody yourself.
  3. Share your link and print the card. Your link is live as soon as that file is deployed: <your-site>/c/<your-username>/. It appears below with a copy button and a QR code. Open Print for a press-ready sheet — the QR always encodes this permanent URL, so the card never goes out of date.

No terminal, no Node.js, no build step: /c/<username>/ is served by the site's own fallback the moment your JSON is there. Optional niceties if you do have Node — npm run build pre-renders each link to a real page (so link previews in chat apps resolve instead of hitting a 404 status) and refreshes this list. SETUP.md covers deploying to GitHub Pages, where .github/workflows/pages.yml does both on every push.

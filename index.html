Print it once. Change the links forever.

QR Link Card is a printable profile card whose QR code points at a URL you control — not at your Instagram, not at your portfolio. Change your links, move platforms, hide your pricing from strangers: the card in someone's wallet updates itself.

The problem with printed QR codes

A printed code is frozen. If it points straight at instagram.com/you, then the day you switch platforms, add a portfolio, or decide a stranger shouldn't see your wholesale pricing — the card is wrong and you have to print it again. Most people just never print one.

Printed: the destination

QR → https://instagram.com/you
  • Change platform → reprint the card
  • Add a portfolio → reprint the card
  • Hide your pricing → too late, it's printed
  • Everyone sees exactly the same thing

Printed: your URL

QR → https://yourdomain/c/rahul123
  • Edit links whenever you like — the card stays correct
  • Strangers see public links only
  • A temporary link unlocks one private link, then expires
  • Approved followers see everything

One URL, three tiers of access

The same printed code serves different content depending on who is holding the phone. Click any card to see it live — these are real pages, not screenshots.

Public

/c/rahul123

A stranger scans the card. They see public links only — Instagram, portfolio, email. The WhatsApp number and the pricing list are simply not there. No account needed.

Temporary

/c/rahul123?t=temp_demo_live

You send a link that expires. The token unlocks exactly one private link — say your pricing list — for 10 minutes or 24 hours. After that the same URL quietly falls back to the public view.

Approved

/c/rahul123 + session

A trusted client signs up and you approve them. From then on they see every link whenever they open your URL. Revoke it any time and they drop back to public.
Honest caveat about V1. This release is a static site: the profile JSON is fetched by the browser, so the private URLs are technically on the visitor's device even though they are never rendered. The tier logic here is the real logic, but enforcement needs a server. That is exactly what V2 adds — see ARCHITECTURE.md.

And it is a real card

89 × 51 mm, 300 DPI, 3 mm bleed, vector QR, a quiet zone that scanners actually need. Download a PDF and hand it to a print shop. These previews are drawn live from the demo profiles.

Who this is for

Freelancers

Public: Instagram, portfolio, email. Private: price list, contract PDF, WhatsApp. Hand out cards at a market — strangers see your work, a serious client gets a 24-hour link to your rates.

Shopkeepers

Public: shop Instagram, Maps pin, catalogue. Private: wholesale pricing, supplier contact, delivery schedule. Slip a card into every order; approve retail partners once.

Students & job seekers

Public: LinkedIn, GitHub, portfolio. Private: resume PDF, reference contacts, personal number. Recruiters get approved access instead of you emailing your phone number to strangers.

No card? Still useful.

The card is optional. Put the URL in your bio, mint expiring links and send them over WhatsApp, approve followers from the dashboard. Everything works digitally — printing is just an upgrade for in-person networking.

How a scan is answered

The whole product is this decision, made on every request. It lives in lib/access.js and is covered by tests.

FUNCTION handleProfileRequest(username, request):
    profile  = getProfile(username)
    registry = getTokensAndFollowers(username)

    IF request has a session AND that user is approved by the owner:
        RETURN render(profile.links [public + followers_only])   # tier: follower

    IF request.query has "t":
        token = registry.find(request.query.t)
        IF token exists AND not expired AND uses remain:
            RETURN render(profile.links [public] + [token.target_link])  # tier: temporary
        ELSE:
            RETURN render(profile.links [public])                # silently fall back

    RETURN render(profile.links [public])                        # tier: public

Notice what never happens: a private URL is never printed, never encoded into a QR, and never served to someone who has not been given it. The printed artefact contains one thing — your permanent URL.

Run it in thirty seconds

Look at the demo

git clone https://github.com/clickalex/GrinCard.git
cd GrinCard
python3 -m http.server 8080
# open http://localhost:8080

No install, no build, no dependencies. A browser and a static server.

Run the tests

npm install      # dev oracles only
npm test         # 59 tests

The QR encoder is compared module-for-module against a reference implementation, and generated PDFs are rendered at 300 DPI and decoded with an independent QR reader.

A template is one file. Drop it in card-templates/community/, add a line to that folder's index.json (or run npm run build:templates and let it write the line for you), and it appears here and in the builder — no core file changes, so a pull request adding a template cannot break anything else.

The QR on its own

For an email signature, a poster, or a sticker.

The QR encodes only the permanent profile URL — never a destination and never a temporary token. That is what makes it safe to print: tokens expire, and a printed code cannot be revoked.
